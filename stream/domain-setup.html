Blue Steel Baseball

Point bluesteelbaseball.com at Vercel

Your site is live on Vercel, but the domain isn’t reaching it. Follow one of the two options below — the first is recommended. Check off each step as you go.

What’s wrong (the short version)

Your domain is registered at GoDaddy, but its nameservers are set to an old host, ns1/ns2.arvixeshared.com (Arvixe). That host runs your DNS and its account is suspended, so:

  • The bare domain shows an “Account Suspended” page.
  • Editing DNS records in GoDaddy does nothing — GoDaddy isn’t in charge of your DNS; Arvixe is. That’s the confusion.
  • www already works because its record points to Vercel.
Recommended · easiest

Option A — Hand your DNS to Vercel

Takes DNS away from the broken Arvixe host. Vercel then sets up the domain automatically — nothing else to maintain.

  1. Sign in at GoDaddy → My Products → Domains → bluesteelbaseball.com → Manage DNS → Nameservers → Change.
  2. Choose “I’ll use my own nameservers.” Delete the two Arvixe ones and enter Vercel’s:
    NS 1 ns1.vercel-dns.comNS 2 ns2.vercel-dns.com
  3. Save. GoDaddy may warn that changing nameservers replaces existing records — that’s expected and fine.
  4. In Vercel → project bluesteelbaseball → Settings → Domains, make sure bluesteelbaseball.com is listed. It flips to a green ✓ once DNS updates.
  5. Wait for it to take effect — usually 10–60 minutes (can be a few hours). Done.
Alternative · keep GoDaddy DNS

Option B — Set the records at GoDaddy

Use this only if you’d rather keep DNS at GoDaddy instead of Vercel.

  1. GoDaddy → domain → Nameservers → Change → “Use GoDaddy default nameservers.” (This takes control back from Arvixe.)
  2. Wait a few minutes, then open DNS Records and set:
    Aname @ → value 216.198.79.1  (delete the old 143.95.69.195) CNAMEname www → value cname.vercel-dns.com
  3. Save. Same green ✓ check in Vercel → Settings → Domains once it propagates.

The Vercel Domains tab is the source of truth. Whatever it shows for the exact record/value — match that. It turns green when correct.

How to know it worked

bluesteelbaseball.com loads the site (no “Account Suspended”).
Vercel → Settings → Domains shows a green ✓ next to the domain.
Both bluesteelbaseball.com/stream and www.bluesteelbaseball.com/stream open the toolkit.

Don’t worry about

The “Account Suspended” page / paying Arvixe. Once DNS leaves Arvixe, that host is out of the picture — no need to revive or pay it.
Breaking www. It keeps working the whole time.
The overlay links. Keep using bluesteelbaseball.vercel.app until the domain is green — those always work.
